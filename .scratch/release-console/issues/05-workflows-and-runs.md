# 05: 工作流与运行列表

**What to build:** 在仓库工作区内，侧边栏可在「工作流」与「运行」之间切换：工作流视图列出该仓库的全部 workflow，运行视图列出 workflow run 并显示状态、分支、事件、触发者与时间；用户可按状态、分支或 workflow 过滤。正在运行的 run 自动刷新，离开视图或切换仓库时轮询停止。
