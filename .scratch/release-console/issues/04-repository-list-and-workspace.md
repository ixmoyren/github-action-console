# 04: 仓库列表与工作区入口

**What to build:** 登录后看到自己名下的全部仓库（含私有）分页加载，可按名称搜索、按最近更新时间或最近推送时间排序，并区分私有与公开；列表具备加载态、空态与错误态。选中一个仓库后进入它的工作区，应用把上次选中的仓库记在 SQLite 里，重启后自动回到该仓库。
