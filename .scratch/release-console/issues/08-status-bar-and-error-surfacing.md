# 08: 状态栏与错误/限流呈现

**What to build:** 应用常驻状态栏显示当前登录用户，以及 GitHub API 的限流余量与重置时间，让用户知道何时该等一等。网络失败、二级限流退避、资源未找到等错误以非阻塞通知呈现，全应用不出现白屏或崩溃；断网与限流时有可见提示。

**Blocked by:** 05（工作流与运行列表）

**Status:** ready-for-agent

- [ ] 常驻状态栏显示当前登录用户
- [ ] 状态栏显示 API 限流余量与重置时间
- [ ] 网络失败、二级限流退避、未找到以非阻塞通知呈现，不弹阻塞对话框打断操作
- [ ] 断网与二级限流下有可见提示，应用不崩溃、不白屏
- [ ] 错误分类到通知文案的映射由纯函数测试覆盖
