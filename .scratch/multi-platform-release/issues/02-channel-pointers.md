# 02: 通道指针：按（发布目标 × 通道）

**What to build:** 通道指针的读写， (发布目标, 通道) 为键、发布版本为值（ADR-0005）。指针只在"发布到通道"这个显式动作里被写入；查询看板时一次取出某仓库的全部指针。单目标构建失败不得改动任何指针，这条要在测试里被钉住。

**Blocked by:** —

**Status:** ready-for-agent

- [ ] 键为 (仓库, 发布目标, 通道)，值为发布版本（tag 名）
- [ ] 写入是显式动作：`发布到通道(target, channel, version)`
- [ ] 读取：某仓库的全部指针，供看板按目标 × 通道展开
- [ ] 未设置的指针与"指向空"可区分（前者显示空的格子，不是错误）
- [ ] 内存 SQLite 往返测试：写入、覆盖、读取、跨仓库隔离
- [ ] 独立性测试：只写一个键，其他键逐字节不变
