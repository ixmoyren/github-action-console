# 08: 发布到通道与独立性演示

**What to build:** 显式动作"发布到通道"：把 (发布目标, 通道) 指针指向某个发布版本；只在该目标该版本的发布资产已存在时允许，否则明确提示"仅登记、产物尚不可获取"。同时准备演示脚本：真实构建一次 → 推进通道 → 看板指针变化 → 故意让另一个目标失败 → 证明其他目标与其他通道的记录不变。

**Blocked by:** 05、06、07

**Status:** ready-for-agent

- [ ] 发布动作：写 (目标, 通道) 指针，记录动作时间与操作者
- [ ] 前置校验：该目标该版本的发布资产不存在时给出提示，不静默放行
- [ ] 发布后看板对应格子立即更新，其他格子逐字节不变
- [ ] 失败对照实验：让一个目标构建失败，断言其他目标 / 通道的指针与发布记录不变
- [ ] 演示材料：真实 run 链接、通道更新前后截图、模拟步骤的标注截图
- [ ] 演示脚本写进交付文档（见 spec 的"演示脚本"）

## Comments

已实现：`ReleaseBoard::publish` 带前置条件（该版本必须有这个目标的发布资产，否则 NothingToPublish 且不写指针）+ 独立性测试（一个目标红、另一个目标的指针不变；其他目标与通道全为空）+ 看板格子上的 发布 按钮。演示脚本见 spec 的 Further Notes。
